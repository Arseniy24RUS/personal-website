GitHub Pages не имеет серверной базы данных, поэтому безопасная версия администрирования работает через GitHub Issues и GitHub Actions: пользователь создаёт заявку, workflow превращает её в JSON-кандидата и отправляет в очередь проверки.

GitHub Pages has no server database, so the safe administration model works through GitHub Issues and GitHub Actions: the user creates a request, the workflow converts it into a JSON candidate and sends it to the review queue.
