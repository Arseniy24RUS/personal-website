На главную · English

Для оценки посещаемости персонального сайта используется Яндекс Метрика. Сервис получает сведения о просмотрах страниц, источниках посещений и переходах по внешним ссылкам. В события передаются адреса без параметров и фрагментов. Длительность визитов и приблизительная география рассчитываются на основе данных о посещениях, браузере и сетевом подключении. Метрика может использовать файлы cookie.

Выбор сохраняется в браузере. Если локальное хранилище недоступно, сбор статистики отключается. Для отключения Метрики на всех сайтах можно установить расширение для браузера.

Privacy and website analytics

The site uses Yandex Metrika to measure its audience. The service receives information on page views, traffic sources, and outbound link clicks. Event addresses exclude URL parameters and fragments. Visit duration and approximate location are derived from visit, browser, and connection data. Metrika may use cookies.

Your choice is stored in this browser. Analytics is disabled when local storage is unavailable. To disable Metrika across websites, install the browser add-on.
